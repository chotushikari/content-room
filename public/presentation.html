✦ Judge Q&A & Defence

Addressing key technical questions

Click any question below to inspect our architectural answers and design rationale.

Q1: Are these real people or AI predictions? How do you maintain honesty? +
Every metric in Content Room is strictly typed as Metric.kind = 'simulated_estimate'. We explicitly never write "100 people think this" — instead we state "100 synthetic agents simulated". Validation status is reported as 'not_established' until benchmark evals are conducted.
Q2: How is Content Room different from OASIS or MiroFish? +
MiroFish and OASIS simulate a world once and output a single prediction report. Content Room is the only system that holds the synthetic population fixed via a deterministic populationHash and re-tests Version B content against the exact same 100 agent IDs to prove before/after lift.
Q3: What happens if third-party LLM APIs fail on stage during a demo? +
Our provider chain automatically falls back: Gemini Flash → Groq Fallback → DeterministicSimulationEngine. The system runs 100% offline with zero network and zero API keys without breaking the user flow.
Q4: How do you prevent AI chain-of-thought leaks and prompt injection? +
All user input is wrapped in <untrusted_content> delimiters, and Zod validates all API boundaries. Raw chain-of-thought is suppressed; only safe execution summaries are rendered.
